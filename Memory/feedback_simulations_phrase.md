When referencing the closed-loop numerical experiments collectively in manuscript/supplement prose, the canonical phrase is **"the simulations"**.

**Correct:** "The clamp is active for $<1\%$ of control steps in the simulations."
**Wrong:** "in the reported runs" / "in the simulated runs".

**Why:** Two rounds of user correction (2026-04-22) moved the text from "reported runs" → "simulated runs" → "simulations". "Simulations" is terser and consistent; "reported runs" is self-referential; "simulated runs" is redundant (numerical simulations are by definition simulated). User wants the shortest, least tautological phrasing.

**How to apply:** Any sentence that needs a collective noun for the $25$ deterministic runs (or the speed-envelope sweep, or the deep-sweep dataset) should use "the simulations". If a more specific referent is needed (e.g., a single trajectory), use "Case~k" / "the Case~k run" / "IC$k$" — not "the Case~k reported run".

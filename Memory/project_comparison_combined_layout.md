**The convention (re-locked 2026-04-30 after iterative resizing):**

`scripts/make_comparison_plots.py` (`Plot H` block) produces:
`Soft_Precise_Landing/Figures/generated/comparison_combined_circular.pdf`

Locked layout:
- `figsize = (18.0, 5.0)` inches.
- `gridspec(1, 4, left=0.05, right=0.99, wspace=0.40)` establishes baseline bboxes; `subplots_adjust(bottom=0.230, top=0.865)` then **manual `set_position()`** on every panel for asymmetric sizing (gridspec alone can't enlarge subplot 1 while shrinking subplots 2–4).
- **3-D bbox**: `ax3d.set_position([0.000, 0.10, 0.24, 0.84])` — flush against the figure's left edge, bbox aspect 0.94 (≈ square) so the 3-D cube fills the bbox horizontally with no flanking whitespace.
- **Bar charts**: shared `bar_y0=0.23, bar_h=0.56` (height shorter than the 3-D bbox so the bars sit lower on the figure); distributed across `bar_left=0.33, bar_right=0.99` with `gap=0.07` between charts → `bar_w = (0.66 - 0.14)/3 = 0.173`.
- **Suptitle**: `fig.suptitle("Landing Performance of Five Controllers across Cases 1–5", fontsize=24, y=0.99)` — note **en-dash** (U+2013), not `--`.
- **Subplot 1 title**: `ax3d.set_title("Landing Performance for Case 5", fontsize=20, x=0.55, y=0.95)`. Custom `x` because the bbox starts at x=0 — default `x=0.5` clipped the title's left side off the figure. `y=0.95` of bbox ≈ figure y=0.90, roughly aligning with bar titles.
- **Subplot 2–4 titles**: `"Landing Time"`, `"Horizontal Precision"`, `"Touchdown Softness"` at `fontsize=20, y=1.03` (above bbox top).
- **Axis labels**: `fontsize=20`. 3-D x/y use `labelpad=12`, z uses `labelpad=2`. Bar y-labels (`landing time [s]`, `final $xy$ error [m]`, `$\|v_\mathrm{rel}\|$ at touchdown [m/s]`) use `labelpad=4`.
- **Tick labels**: bar `xticklabels(rotation=20, fontsize=16)`, bar `tick_params(axis="y", labelsize=16)`; 3-D `tick_params(pad=1, labelsize=14)`.
- **Common legend**: `fig.legend(handles, labels, loc="lower center", bbox_to_anchor=(0.5, 0.0), ncol=5, fontsize=14, handlelength=1.6, columnspacing=2.0, handletextpad=0.6, frameon=False)` — 5 entries (MDF-ASMC + Baselines A–D) in one row.
- **Save** with `fig.savefig(...)` — no `bbox_inches="tight"` (drops the 3-D z-axis label).

**Why manual `set_position()` after gridspec**:
gridspec only redistributes width by `width_ratios`; it can't shrink the bar bbox heights independently of the 3-D bbox height. The user-requested layout has the 3-D panel **taller** than the bar charts (bar `h=0.56` vs 3-D `h=0.84`). `set_position()` is the only mechanism that allows that asymmetric vertical sizing.

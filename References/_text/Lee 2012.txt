Adaptive Image-Based Visual Servoing for an Underactuated
Quadrotor System

This paper presents an adaptive image-based visual servoing (IBVS) integrated with adaptive sliding mode control
for a vision-based operation of a quadrotor unmanned aerial vehicle (UAV). For a seamless integration with
underactuated quadrotor dynamics, roll and pitch channels are decoupled from the other channels using virtual
features. This allows a simple and accurate algorithm for estimating depth information and successful application of
the proposed guidance and control algorithm. By employing an adaptive gain in the IBVS control method, the chance
of image feature loss is reduced, and performance and stability of the vision-guided UAV control system are
improved. The overall setup allows image features to be placed at the desired position in the image plane of a camera
mounted on the quadrotor UAV. Stability of the IBVS system with the controller is proved using Lyapunov stability
analysis. Performance of the overall approach is validated by numerical simulation, vision integrated hardware-in-
the-loop simulation, and experiments. The results conﬁrm that the target image is successfully placed at the desired
position of the image plane and the quadrotor state variables are properly regulated, showing robustness in the
presence of sensor noise, parametric uncertainty, and vibration from motors.

Introduction
V
ISUAL-INFORMATION-BASED control, or visual servoing,
is a method of controlling a robotic system to its desired states
using visual feedback obtained from a camera [1,2]. It has received
growing interest during the recent decades and has been applied to
various robotic systems [3–14].
Visual servo systems are often divided into two categories,
namely, position-based visual servo (PBVS) systems and image-
based visual servoing (IBVS) systems [2]. PBVS systems estimate
state variables, i.e., position and attitude, of the target of interest with
respect to the camera coordinate frame using the visual information.
Error between the current and the desired states in the Cartesian
coordinate space is deﬁned as the task space to control the camera
state. The fact that the task space can be deﬁned in this way, which is
commonly usedin roboticsand control, is one of themain advantages
of the position-based servoing. On the other hand, the sensitivity of
the state estimation to the camera calibration error is a disadvantage.
Various methods to compute the relative position and attitude of the
target with respect to the camera have been researched in computer
vision and robotics [15–17], as well as applications of PBVS control
for unmanned aerial vehicles (UAVs) [3,4,18–20]. These appli-
cations used PBVS as sensors rather than tightly integrating vision in
the feedback control loop. Most conventional cameras capture 30
frames per second and the computation rate for estimation of the
position and attitude is usually less than 30 Hz. This is not fast
enough to stabilize the UAV (for example, inertial sensors provide
attitude information of UAV at 100 Hz or faster, and control
command is also given at a high frequency), so PBVS is used for
position guidance only in many UAVapplications.
A linear pose estimation algorithm has been proposed for landing
an UAV [21]. For real time, vision-based landing of an autonomous
helicopter [22], invariant moments have been used to estimate the
yaw-axis orientation with respect to the helipad. As a visual
odometer for an autonomous helicopter [23], a template method has
been used to ﬁnd target displacement from an input image. Then it
has been used to estimate translational displacement for a six-degree-
of-freedom testbed. A pose estimation method using two cameras,
one of which is a pan-tilt [24], has been implemented on a tethered
quadrotor system. For PBVS-based position control of a quadrotor
[25], two pose estimation methods have been tested: a perspective N-
points method and a homography-based method. Both algorithms
showed satisfactory results, however, the algorithms were sensitive
to the camera calibration result.
IBVS systems use the error between the current image and the
desired image features in image space, rather than in Cartesian space,
as a task space to control the camera state. Since IBVS systems use
the position of image features in image space directly, the estimation
of the camera state is not necessary thereby increasing robustness to
the camera calibration error. Furthermore, because three-dimen-
sional reconstruction is not required in IBVS, the computational load
of IBVS is lighter than PBVS. This allows the IBVS system to be
implemented with an inexpensive micro processing unit and run in
real time. Although IBVS is known to have difﬁculties with camera
retreat, techniques to avoid it have been proposed such as using
polar coordinates [26]. Further discussions on the IBVS, PBVS,
and the hybrid approach combining those two can be found
elsewhere [27].
In optical ﬂow-based IBVS-based control approaches, an image
Jacobian matrix plays a signiﬁcant role. It links the velocities in the
camera coordinate to the velocities in the image coordinate and is
used to derive velocity references for the camera or to obtain the
camera state. Various strategies that make use of the image Jacobian
matrix have been researched for robotic manipulators with a camera
ﬁxed on an end-effector of the manipulators [1,2,6–11]. The optical
ﬂow-based IBVS system generates velocity references so that the
end-effector can be placed at the desired position and attitude by
tracking the references. This can be easily done for robotic
manipulator systems because they can usually control the position
and attitude state variables independently to minimize the state error.
However, because of the highly-coupled complexity of the image
Jacobian matrix, it is difﬁcult to integrate the IBVS within system
controllers having limited degrees of freedom. By concentrating on
the image plane, IBVS might cause improper or unnecessary
motions. So far, there have been only a few IBVS implementations
for real plants. IBVS has been employed invarious work [14,28–30].
IBVS has been considered for an indoor blimp [28] and a robotic
airship [29]. A pan-tilt camera has been used for a ground robot [30].
IBVS has been used to locate the center of the UAVat the centroid of
feature points [14]. A rule for generating the steering velocity
command for a ground robot, which minimizes the visual target
tracking error, has been presented [12]. Similarly, the object location
in the image has been used to generate the separate velocity
references in the lateral and vertical directions for an autonomous
helicopter [31]. Then a separate proportional-integral-derivative
(PID) controller was designed for each attitude control channel. Even
fewer reports exist on integrated IBVS systems with nonlinear
controllers for underactuated dynamic systems. The position of the
image centeroid of a given target in the camera ﬁxed frame has been
presented for IBVS [13,14]. The desired image dynamics was chosen
to inherit the orientation of the camera, and a backstepping controller
for a quadrotor is proposed. IBVS provides the position in the image
plane and additional sensors were used to measure angular and
translational velocities.
This paper concerns two issues in applying an optical ﬂow-based
IBVS [1] to an underactuated system. The ﬁrst issue is that it is
difﬁcult to apply an optical ﬂow-based IBVS for a system that has
limited degrees of freedom. The optical ﬂow-based IBVS method
generates six references (three for velocities and another three for
angular velocities) simultaneously using image velocity, so many
researchers apply it to a fully-actuated system such as a robotic
manipulator. The second issue of combining the IBVS with an
underactuated system is that the image features may leave the image
plane during operation, in which case visual servoing cannot be
implemented. For example, let the underactuated system be a
rotorcraft UAV and a camera be mounted on the center of UAV,
looking downward. Suppose that the desired positions of image
features are placed at the center of the image plane and the current
image features are on the right side of the image plane. To move the
image feature to its desired position the UAV should move to right,
which means tilting to right, so that the image feature may leave the
image plane.
In this paper, an optical ﬂow-based IBVS control method is
integrated with an underactuated quadrotor system (Fig. 1).
Quadrotor UAV systems possess great maneuverability and are
potentially simpler to manufacture. Because of these advantages,
quadrotor helicopters have received much interest in UAV research.
Previously, linear and nonlinear controllers for a quadrotor system
have been proposed. Proportional-derivative and PID controllers
have been considered to control roll and pitch angles with
consideration for blade ﬂapping, and to control altitude and position,
respectively [32]. These controllers operate at a high speed in the
presence of wind disturbance. A nested-saturation technique has
been introduced to control a chain of integrators bounded input [33].
The controller uses three torques with respect to x, y, and z axes for

Also, x and y axes are controlled by roll and pitch control. The overall

underactuated quadrotor dynamics [35]. This controller uses slack
variables to overcome the underactuated property of a quadrotor
system and it is robust to internal and external uncertainties.
In this study, an optical ﬂow-based IBVS control method is
successfully integrated with adaptive sliding mode control for an
underactuated quadrotor system such that a target will be placed at
the desired position and attitude with respect to a camera ﬁxed on the
quadrotor system. The adaptive sliding mode controller is designed
using augmented slack variables to overcome the underactuated
property of the quadrotor. Adaptive rules for this controller are
developed to strengthen the robustness to external disturbances and
internal uncertainties. Also, to achieve tight integration with an
optical ﬂow-based IBVS method, the proposed IBVS uses an image
Jacobian matrix to generate the velocity references for the
underactuated system with decoupled roll and pitch angles. This
decoupling can be easily donewith a pan-tilt camera. However, small
UAVs such as the indoor quadrotor considered in this paper have a
limitation on takeoff weight and space to mount the gimbal
equipment. To decouple roll and pitch from the other channels with a
ﬁxed camera, virtual image features are deﬁned from a virtual
coordinate frame. The vertical axis of the virtual coordinate frame is
always aligned with the vertical axis of the inertial coordinate frame
so that the roll and pitch angles with respect to the inertial frame are
zero. The virtual image features can be derived from the coordinate
rotation, translation, and depth estimation. By using IBVS as a
guidance block (rather than a controller), and using the virtual
coordinate frame, the proposed approach is not susceptible to the
problems of the conventional approach that might cause improper or
unnecessary motions. By using the image Jacobian matrix associated
with thevirtual image features, reference signals for the roll and pitch
angular velocity are decoupled so that the proposed visual servo
control method can be applied to the underactuated quadrotor
dynamics. Acquisition of the depth information from a single camera
is one of many signiﬁcant problems currently under study in the
machine vision ﬁeld. In this paper, a simple and accurate depth
estimation algorithm for IBVS in quadrotor system is presented.
To our knowledge, the only study aimed to keep the image features
in the image plane for underactuated systems is concerned with
unmanned ground vehicles (UGVs), not UAV. For that purpose,
multiple reference features have been used [36]. If so, even when one
reference object moves out of the ﬁeld of view (FOV), another
reference objects remain within (or enter) the FOV. Therefore the
UGV can operate without losing stability. In this paper, an adaptive
IBVS strategy is proposed to prevent the loss of the image feature for
the quadrotor. By using the adaptive IBVS as a guidance command
for control, image features are kept in the image plane during
operation so reliability of the IBVS system is improved.
The underactuated UAV systems need position guidance to control
their position state. One of the usual approaches for UAV position
guidance is based on the Global Positioning System (GPS). How-
ever, the position data from a stand-alone GPS usually contain error
in the order of several meters, which is not enough for precise landing
of a small quadrotor or helicopter. Differential GPS can guarantee
position accuracy to the few centimeter level, but it requires a
stationary station. Also, for object tracking missions, there is no way
to obtain a guidance to track the object without visual information.
Therefore, there could be two stages of guidance for UAVoperations:
one using a GPS or other position sensor for rough guidance (or
patrol), and the other using a camera for accurate guidance such as
landing (or tracking). So once the landing pad or the target is detected
in image space during the ﬁrst stage, then the accurate UAV
movements are controlled by switching to the second stage. This
paper is mainly interested in the second stage, and adaptive visual
guidance is proposed and validated by real experiments.
Figure 2 presents the control architecture for the quadrotor system
using the proposed IBVS method in the control loop. Target features
are extracted from the camera images and modiﬁed to overcome the
underactuated property of the system. Also, a depth estimation
algorithm is presented in order to implement the IBVS guidance,
which is rendered simple yet effective due to the decoupling of roll
and pitch axes. The IBVS generates reference velocities to place the
target at the desired position in the image plane. Then the proposed
adaptive sliding mode controller derives control inputs to track the
references, and the position and angular rate data from a motion
capture system (from VICON) and inertial measurement unit (IMU)
are used for the control.
This paper is organized as follows. In Sec. II, the operating
principle of a quadrotor and its dynamic equations are presented. In
Sec. III, visual servoing is brieﬂy reviewed and the image-based
control strategy for an underactuated system is proposed. In Sec. IV,
the adaptive sliding mode controller and the corresponding error
analysis is presented. Section V presents experimental and simu-
lation results and Sec. VI contains concluding remarks.
II.
Quadrotor Helicopter Model
The quadrotor helicopters considered in this paper have four ﬁxed-
pitch-angle blades as shown in Fig. 1, unlike classic helicopters that
have variable-pitch-angle blades. The quadrotor helicopter is
controlled by varying the speed of each rotor. The concept of
operating the quadrotor helicopter is depicted in Fig. 3. Each rotor
produces lift force and moment. The two pairs of rotors, i.e., rotors 1
and 3, and rotors 2 and 4 in Fig. 3, rotate in opposite direction so as to
cancel the moment produced by the other pair. To make a roll angle
() with respect to the x-axis of the body frame, the angular velocity
of the rotor 2 can be increased and the angular velocity of the rotor 4
can be decreased while keeping the total thrust constant. Likewise,
the angular velocity of the rotor 3 is increased and the angular
velocity of the rotor 1 is decreased to produce a pitch angle () with
respect to the y-axis of the body frame. To perform yawing motion
( ) with respect to the z-axis of the body frame, the speed of the
rotors 1 and 3 are increased and the speed of the rotors 2 and 4 are
decreased.

Adaptive Visual Servo Control
for a Quadrotor Helicopter
This section ﬁrst presents a brief review of the camera geometry
then, based on the analysis of the image dynamics for an
underactuated system, a control law for the control reference signal is
proposed to minimize the image location error in the image plane.

B.

Underactuated System
Classical IBVS control schemes that generate six velocity
reference components have usually been applied to fully actuated
systems. However, as described in Sec. II, the quadrotor helicopter is
an underactuated system and the six state variables cannot be
controlled independently. It is challenging to apply the IBVS control
method for an underactuated system like the quadrotor. For example,
suppose that the IBVS generates the positivevelocity reference along
the xaxis and negativeangular velocity referencewith respect to the y
axis ( _) simultaneously. Then the quadrotor helicopter cannot be
controlled to track the references because, as shown in Eqs. (5) and
(6), the quadrotor cannot move, i.e., the positive x direction with
negative pitch angle. To overcome the complexity caused by
coupling, _ and _ reference generation is decoupled with the IBVS
system.

3.
Experiment
A quadrotor platform as shown in Fig. 25 is developed to validate
the proposed algorithm. The quadrotor has tip-to-tip wing span of
60 cm, height of 12 cm, and weight of about 1250 g including two
batteries.
A quadrotor is equipped with 1.2 GHz wireless camera for the
image transmission. The video is transmitted to a receiver connected
via a USB image grabber. An image is captured 30 times in a second
with a width of 320 pixels and a height of 240 pixels, and the FOV is
about 50 deg.
Two gyroscope sensors are used to measure angular velocity of the
quadrotor: one is a single-axis gyroscope to sense yaw rate, the other
one is a dual-axis sensor to sense roll and pitch rates. A triaxial
accelerometer is used to fuse with the gyroscopes to estimate roll,
pitch, and yaw angle in radian units and bias of a gyroscope.
The attitude of the quadrotor is controlled by an onboard
microprocessor. A reference velocity is generated from the host
computer based on two kinds of operation modes: mode 1 is position-
based hover control to move quadrotor to near to a marker, and mode
2 is IBVS control which is proposed in this paper to move the
quadrotor to desired image coordinates. A signal route diagram is
shown in Fig. 26.
To make the proposed algorithm work, four image points need to
be extracted repeatedly. For this, a ﬁducial marker [39] with tracker
[40] is used. The tracker extracts four corners of a ﬁducial marker
from a captured image then returns its calibrated image coordinates.
The processing throughput of thetracker is over 25 frames per second
which is enough for position guidance and navigation of the
quadrotor system. A ﬁducial marker and tracking result are shown in

VI.
Conclusions
An adaptive image-based visual servoing (IBVS) control scheme
is proposed for an underactuated unmanned aerial vehicle (UAV)
system using optical ﬂow. Generally, for underactuated UAVs, image
targets may leavethe image plane during the IBVS control, so that the
system could become unstable. To keep the image feature in the
image plane, an adaptive gain for IBVS method is presented, which
maintains the stability of the IBVS-based control scheme. A simple
depth estimation algorithm is used to implement the IBVS guidance.
To achieve the expected performance of optical ﬂow-based IBVS for
underactuated systems, the coupled dynamics of roll and pitch
channels are considered explicitly. With use of a virtual image,
velocity references for roll and pitch angles are decoupled so that the
IBVS control scheme can be successfully applied to the under-
actuated quadrotor system. The proposed IBVS method is tightly
integrated with the proposed neural network-based adaptive sliding
mode controller for the quadrotor UAV. By augmenting inputs to the
quadrotor with slack variables, the proposed adaptive sliding mode
controller overcomes the underactuated property. Furthermore, the
uncertain ground effect and input augmented slack variables are
estimated so that control can be performed precisely near the ground.
The vision system is integrated with a hardware-in-the-loop
simulation setup to test the effect of noise associated with camera and
hardware. Also indoor hardware experiments have been performed
to validate the proposed algorithm under vibration from motors,
image noise, and model uncertainties. The results show satisfactory
performance of the proposed adaptive IBVS integrated with adaptive
sliding mode control for the UAV under these conditions.

Constrained Image-Based Visual Servoing using Barrier Functions
Iman Salehi, Ghananeel Rotithor, Ryan Saltus, Ashwin P. Dani
Abstract— This paper presents a novel constrained image-
based visual servoing (IBVS) approach that guarantees target
features to remain within the camera ﬁeld of view (FOV)
for the duration of the task. Barrier function (BF) is used
to transform the feature dynamics on the image plane into
equivalent dynamics with full state constraints. An IBVS
controller is designed for the full state constrained system that
regulates the original system. A stability analysis is provided
to prove the local asymptotic convergence of the state error in
the sense of Lyapunov. Simulation and robot implementation
results show the efﬁciency of the proposed method to reach
the desired features from any initial conﬁguration while the
visibility constraints of the feature points are being realized.
I. INTRODUCTION
Image-based visual servo (IBVS) is a closed-loop control
scheme that uses camera image feedback to control the
motion of the robot. In the popular eye-in-hand conﬁgu-
ration, the camera is mounted near the end-effector of a
robot manipulator whose motion can be controlled using the
information from the images for tasks such as grasping. In
another scenario, the camera mounted on a mobile robot
can also use image feedback to regulate its position to a
desired goal position or for target tracking applications. It is
essential to control the joint motion of the robot such that
all the detected feature points remain in the ﬁeld of view
(FOV) for the continuous availability of image feedback.
However, maintaining visibility of the feature points is a
difﬁcult task to achieve due to multiple factors regarding
the geometry of the scene and the camera [1], [2]. The
feature points’ dynamics are governed by their time-varying
distance from the camera, which is an unknown parameter.
In traditional IBVS control, approximations such as constant
depth is used [3]. Another source of uncertainty is due to
inaccurate camera calibration, as intrinsic camera parameters
are required for the computation of the image Jacobian.
Such uncertainties in the feature dynamics result in unde-
sired transients and deformed camera (robot) trajectories,
leading to loss of visibility of the feature points. A standard
method to remedy such transients and unwanted trajectories
in traditional IBVS is to tune the control gains empirically,

control which switches between image feedback and predic-

The unknown parameters in the image Jacobian can be es-
timated to reduce the uncertainty and improve the IBVS tra-
jectories. In [9]–[13], observer-based methods are presented
to estimate the time-varying depth of feature points, which
can be used to reduce uncertainty in the image Jacobian.
In [14], the authors propose an adaptive tracking controller,
which ensures global asymptotic position and orientation
tracking using an uncalibrated camera. However, the IBVS
trajectories can be constrained to ensure the feature points
remain in the FOV without estimating the unknown param-
eters in the image Jacobian. In [15], an iteratively computed
trajectory is tracked to maintain the features in the camera
FOV. In [7], [16], [17], the transient response of the error
dynamics is constrained through logarithmic transformations
to ensure that the feature points remain in the camera FOV. In
[1], a task prioritization based control law is developed that
maximizes motion perceptibility to keep multiple moving
targets in the FOV. In [18], a position-based visual servo
(PBVS) and a backward motion switching controller is used
to achieve the same objective. A dynamic visibility checking
algorithm is proposed in [19] to check if the features stay
in FOV before applying control. In [20], an adaptive image-
based controller with visibility constraint for leader-follower
formation is developed considering mobile robot kinematics.
A convex 3D visible set is in [21] introduced for PBVS, and a
trajectory in this set is followed to ensure feature visibility. In
[22], a constrained optimization method is developed to plan
a trajectory which is then tracked using an IBVS controller.
The constraints are derived from the workspace objects and
FOV requirements for feature points. In [23], a homography-
based visual servo controller is developed for nonholonomic
mobile robots with FOV constraints.
Barrier Lyapunov function (BLF) is a method used to de-
sign controllers for systems with output and state constraints.
The constraints are, in general, expressed as the system
state or the output bounds. In [24], BLF is deﬁned only to
constrain the output or the partial state of the system. The
control barrier function (CBF) approach is another method

IBVS controller that guarantees the desired features never

dynamics with full-state visibility constraints to an equivalent
system dynamics with no constraints. An IBVS controller
is developed for the transformed dynamics that, through
the stability analysis, is proven to be locally asymptotically
stable. The proposed method is evaluated through numerical
simulations, and its performance is demonstrated on a Baxter
robot to illustrate the method’s ability to adapt to real-world
applications.

VI. CONCLUSION
A constrained IBVS controller is developed in this paper
which keeps the feature points within the camera FOV. A
logarithmic barrier function transformation is used to derive a
new image feature state dynamics. A controller is developed
using the constrained state space dynamics for which a
local asymptotic stability is shown using Lyapunov stability
analysis. The results of the new controller are compared
to the unconstrained IBVS controller in simulation. The
results demonstrated the ability of the developed controller
to maintain all the image plane feature points in the FOV
in contrast to the unconstrained IBVS controller. A robot
experiment is carried out to demonstrate the results of the
constrained controller using the wrist camera of the Baxter
robot.
